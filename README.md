# De Koffieboot

Kale eerste versie van de website van De Koffieboot: een Amsterdamse pont als buurtkoffiezaak aan het Zijkanaal in Amsterdam-Noord, als 3D-scène (three.js).

## Mappen
- `index.html`: de pagina (titel bovenin, 3D-scène, knop Dag/Avond)
- `js/scene.js`: de scène (boot, interieur, omgeving, licht)
- `js/three-extra.js`: three.js-uitbreidingen (water, nabewerking)
- `lib/three.min.js`: three.js r128
- `mensen/`: de mensen (geometrie en texturen)

## Online
Via GitHub Pages: Settings > Pages > Deploy from a branch > `main` / root.
